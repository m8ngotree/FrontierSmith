# Budgeted Convex-Dominance Activation
## Problem
You are given `N` distinct lattice points in `D` dimensions. Point `i` has coordinates
`(x_{i,1}, x_{i,2}, ..., x_{i,D})` and an integer score `P_i`.

You may choose up to `K` points as **seeds**. These seeds become **activated** initially.
Activation then spreads by the following rule:

A point `k` must also be activated if there exists a convex combination of the **currently activated** points whose coordinates dominate point `k` coordinate-wise. Formally, if there exist non-negative reals `lambda_i` over activated points such that:

- `sum lambda_i = 1`, and
- for every coordinate `c = 1..D`,
  `sum (lambda_i * x_{i,c}) >= x_{k,c}`,

then point `k` becomes activated as well.

This rule is applied repeatedly until no more points can be activated. The final set is the **closure** of your seed set.

Your task is to output any seed set with high total score of its closure. Optimality is not required; better solutions receive better scores.

## Input
The input is given in the following format:

```text
D N K
x_{1,1} x_{1,2} ... x_{1,D} P_1
x_{2,1} x_{2,2} ... x_{2,D} P_2
...
x_{N,1} x_{N,2} ... x_{N,D} P_N
```

- `D`: number of dimensions
- `N`: number of points
- `K`: maximum number of seeds you may output

## Output
Output a seed set in the following format:

```text
m
i_1 i_2 ... i_m
```

where:
- `0 <= m <= K`
- `i_1, i_2, ..., i_m` are distinct 1-based indices of chosen seed points
- if `m = 0`, the second line may be empty

## Feasibility requirements
Your output is **feasible** iff all of the following hold:

- `m` is an integer with `0 <= m <= K`
- every printed index is an integer in `[1, N]`
- all printed indices are distinct

For a feasible output, the judge computes the closure `Cl(S)` of your seed set `S` as the **smallest** set satisfying:

- `S ⊆ Cl(S)`, and
- whenever a point is coordinate-wise dominated by a convex combination of points already in `Cl(S)`, that point also belongs to `Cl(S)`.

If the output is infeasible, the submission receives score `0` on that test.

## Objective
Maximize

```text
F(S) = sum of P_i over all i in Cl(S)
```

where `S` is your seed set and `Cl(S)` is its closure.

## Scoring
For each test case:

- Let `R = F(S)` for your output.
- Let `R+ = max(R, 0)`.
- Let
  `U = sum of max(P_i, 0)` over all points. This is an instance-wise upper bound.
- Let
  `B = max(0, max_j F({j}))`, the best score obtainable by choosing **at most one** seed.
  This is the baseline.

The normalized score for the test case is:

- if `U = B`: `1` iff `R+ = B`, otherwise `0`
- otherwise: `max(0, (R+ - B) / (U - B))`

The total contest score is the sum of normalized scores over all test cases (possibly scaled by the contest system).

Thus:
- matching the baseline gets score `0` for that case,
- improving beyond the baseline gets a proportionally higher score,
- reaching the upper bound `U` gets score `1`.

## Constraints
- `2 <= D <= 8`
- `1 <= N <= 1000`
- `0 <= K <= 30`
- `1 <= x_{i,c} <= 10^9`
- all point-coordinate vectors are pairwise distinct
- `-10^7 <= P_i <= 10^7`
- Time limit: `5 seconds`
- Memory limit: `1024 MiB`

## Example
Input:

```text
2 3 2
1 4 2
4 1 3
2 2 1
```

One possible output:

```text
2
1 2
```

Explanation:

- Seeds are points `1` and `2`.
- Using the convex combination `0.4 * point_1 + 0.6 * point_2`, we get coordinates `(2.8, 2.2)`, which dominate point `3 = (2, 2)` coordinate-wise.
- Therefore point `3` is also activated.
- The closure is `{1, 2, 3}` with total score `2 + 3 + 1 = 6`.

For this instance:
- `U = 6`
- the best one-seed solution has value `B = 3`
- this output achieves the upper bound, so its normalized score is `1`.
